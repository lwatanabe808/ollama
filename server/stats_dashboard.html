Average speed by model

Tokens written per second (tok/s): total tokens written ÷ total time spent writing, across this model's requests. Doesn't include loading the model or reading the prompt. Higher is faster.

Where the time goes

Average seconds per request, split into loading the model, reading the prompt, and writing the answer. Loading plus reading is the wait before the first word.

    What's in this suite

    Performance scenarios change one thing at a time and don't grade answers. Fact checks grade answers and are reported separately, so speed and correctness never mix. Known-answer checks make the model reply in a fixed JSON shape, so grading is exact.
